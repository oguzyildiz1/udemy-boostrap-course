# Pricing Cards Project

A responsive pricing comparison component displaying two pricing tiers with different features and benefits.

<img src="img/pricing-cards.png" alt="pricing-cards" width="600" height="">


## ✨ Features

- **Two Pricing Tiers**: 
  - Free tier ($0) - for freelancers
  - Pro tier ($100) - for agencies
- **Responsive Design**: Adapts from 1-column (mobile) to 2-column layout (desktop)
- **Visual Hierarchy**: 
  - Free card: Light background with dark button
  - Pro card: Dark background (black) with light text and button
- **Icons**: Checkmarks from Bootstrap Icons for feature lists
- **Consistent Spacing**: Proper padding, margins, and gaps using Bootstrap utilities

## 🛠️ Components Used

- **Grid System**: Bootstrap grid (col-md-6) for responsive columns
- **Cards**: Bootstrap card component with custom styling
- **Lists**: List groups for feature display
- **Buttons**: Styled subscribe buttons with rounded corners
- **Shadows**: Shadow effects for depth (shadow-lg)
- **Typography**: Poppins font for modern aesthetic

## 🎨 Design Details

### Color Scheme
- **Free Tier**: White/Light background with dark text
- **Pro Tier**: Black background with light text (high contrast)
- **Buttons**: Dark on light (Free), Light on dark (Pro)
- **Accents**: Muted text for descriptions, checkmark icons

### Typography
- **Font Family**: Poppins (Google Fonts)
- **Font Weights**: 300 (light), 400 (regular), 600 (semibold), 700 (bold)
- **Sizes**: fs-1 for main headings, fs-5 for list items

### Spacing & Layout
- **Container**: Max-width 800px on screens ≥800px
- **Gaps**: Consistent vertical spacing (gap-2) between list items
- **Padding**: p-3 for card padding
- **Margins**: my-5 for top/bottom spacing
